## 1. TC-ITEM-STD-005 标准商品必填项缺失时创建失败

- 优先级：P0
- 所属模块：商品管理 → 商品 → 标准商品
- 场景族：create、required
- 风险分：175
- 风险理由：P0 核心业务风险；XMind 已有场景；覆盖商品创建主链路；防止无效必填数据入库
- 来源：xmind-existing ← 标准商品 / 新增 / 必填项缺失 / 新建标准商品，必填项缺失，新建失败
- 审核状态：pending-human-review

### 前置条件

1. 登录商品中心，选择商户(Brand ID为:000407)，点击确定进入商品中心首页

### 测试步骤

1. 点击侧边栏【商品管理】-【商品】，进入商品列表页
2. 点击右上角【新增商品】按钮，进入选择商品类型页面
3. 点击【标准商品】-【去创建】，进入创建标准商品页面
4. 保持「商品名称」为空，不输入任何内容
5. 「商品规格」选择【单规格】；「标准价」输入 10.00
6. 点击右上角【保存】按钮

### 预期结果

1. 保存失败校验：页面仍停留在创建页，未出现「提交成功」提示
2. 必填提示校验：「商品名称」字段出现必填校验提示（飘红/文案提示）
3. 列表无新增：返回商品列表，不存在因本次操作产生的新商品记录
