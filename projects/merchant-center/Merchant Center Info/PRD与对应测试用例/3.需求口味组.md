# 3. 需求口味组

口味组列表与维护、组增删改与同步、商品内口味组加价/默认选中覆盖。组成：S05(口味) + S06 + S08(口味)。

## S05 口味组

- 查询条件：
    - 查询条件记忆支持，切换页面、页签，返回页面保留原有的查询记录（缓存到账号），数据记忆最多展示最近的10条，记忆做自动清空，重新登陆或关闭浏览器再打开，数据记忆消失。
  - 列表：
    - 口味组默认展示：口味组名称、口味名称、价格、默认选中。
    - 口味组默认收起：第二语言（口味组、口味名称）、展示名称（口味组、口味名称）、口味编码、口味图标、设备编码、描述。
  - 新增：
    - 新增子项：输入文本，组内不可重复；规格子项品牌内不可重复。
  - 问号说明参照4.7。

## S06 组的新增编辑删除逻辑

- 组增删改逻辑：
    - 组新增：直接新增无影响。
    - 组内子项新增：
      - 组未被任何商品使用，子项新增即可。
      - 组被商品使用，子项新增不会应用到使用该组的商品，做好提示说明。
    - 组编辑：
      - 组内编辑子项价格/默认选中，不会自动同步到已使用选项组的商品中，做好提示说明。
      - 组未被任何商品使用，组编辑即可。
      - 组被商品使用，组编辑会影响所有使用该组的商品，做好提示说明。
    - 组内子项编辑：
      - 组未被任何商品使用，子项编辑即可。
      - 组被商品使用，子项编辑会影响所有使用该组子项的商品（价格、默认选中除外），做好提示说明。
    - 组删除：
      - 组未被任何商品使用，组内无子项，组删除即可。
      - 组被商品使用，解除和商品关联关系，子项删除后，组才可删除，做好提示指引。
    - 组内子项删除：
      - 组未被任何商品使用，子项删除即可。
      - 查询所有使用该子项商品清单，都×掉，才可删除子项；所有子项删除后，空组情况提示不可保存。
  - 保存与关闭：
    - 保存按钮：
      - 校验组内容，若不完整，提示“请补充完整信息”。
      - 若完整，提交并保存，所有信息生效。
    - 关闭按钮：
      - 无保存数据：直接关闭，不保留数据。
      - 已有数据编辑中：
        - 若组内容不完整，提示“请补充完整信息”。
        - 若组内容完整，弹出提示“是否保存修改？”
        - 选择【保存修改】执行保存。
        - 选择【放弃修改】关闭弹窗，不保存调整。
  - 新增组（未添加子项）：
    - 点击【保存】提示“请先添加子项再保存”。
    - 点击【关闭】直接关闭，不保存数据。
  - 编辑组（删除所有子项）：
    - 点击【保存】提示“请添加至少一个子项后再保存”。
    - 点击【关闭】提示“请保留子项，否则修改不生效”；关闭后，改动不保存。
  - 商品引用组时，同步组字段信息：
    - 规格组：基础信息同步规格组名称、组第二名称；商品信息同步规格名称、规格名称第二语言、规格值、默认选中；规则同步排序。
    - 口味组：基础信息同步口味组名称、组第二名称；商品信息同步口味名称、口味名称第二语言、加价、默认选中；规则同步排序。
    - 做法组：基础信息同步做法组名称、组第二名称；商品信息同步做法名称、做法名称第二语言、加价默认选中；规则同步排序。
    - 加料组：基础信息同步加料组名称、组第二名称；商品信息同步加料名称、加料名称第二语言、编码、最小数量、最大数量、子项商品价格、单次加价、默认选中；规则同步排序、最少选择份数、最多选择份数、份数内免费。
    - 套餐组：基础信息同步套餐组名称、组第二名称；商品信息同步商品名称、名称第二语言、编码、最小数量、最大数量、子项商品价格、单次加价、默认选中；规则同步排序、添加、移除、最少选择份数、最多选择份数、份数内免费。
  - 组内部分字段不展示在商品上。
  - 组基本信息自动同步，商品信息、规则不自动同步。
  - 五个组被引用后，组修改保存时增加同步流程（同步到已关联商品）。
    - 先执行保存流程，再执行同步流程，同步商品默认勾选。
    - 展示的商品为与该组已关联的商品。
  - 五个组新增组覆盖同步商品功能——同步至商品。
    - 同步至商品范围：所有状态为启用（起售）的商品。
    - 两个Tab，已关联组商品、新商品。
    - 已同步商品默认勾选。其他未同步过商品手动选择。
    - 覆盖同步范围：商品信息、规则信息。
  - 商品可修改内容：移除组子项，可以选择组内子项。

## S08 商品内选项组逻辑调整

- 商品内选项组（口味、加料、做法、套餐-组合搭配）添加后支持编辑加价/单次加价、默认选中。
  - 加价/单次加价：
    - 商品添加对应组，带入组内维护的价格。
    - 添加到商品内可调整子项价格，编辑后只在商品内生效，不影响选项组信息。
    - 商品添加组内新子项时，取组内新子项最新价格设置。
  - 默认选中：
    - 商品添加对应组，带入组内维护的默认选中。
    - 添加到商品的选项组，可调整组内默认选中。
    - 商品添加组内子项，提交时校验默认选中唯一性。
      - 商品内新增选项组，直接将选项组内默认选中带入（如有）。
      - 商品内已有选项组，且未维护默认选中，添加子项，子项有默认选中，带入默认选中；子项无默认选中，带入后整组无默认选中信息。
      - 商品添加选项组，选项组已有默认选中子项，选项组新增子项，且该子项非默认选中项。商品添加子项，默认选中项不变。
      - 商品添加选项组，选项组已有默认选中子项，选项组新增子项，将新增子项设置为默认选中项。商品添加该子项，识别商品内该选项组是否已有默认选中，如果已有，新增子项的默认选中不带入；如果没有，新增子项的默认选中带入商品。
  - 组编辑逻辑调整：
    - 组内编辑子项价格/默认选中，不会自动同步到已使用选项组的商品中，做好提示说明。
    - 组编辑：
      - 组未被任何商品使用，组编辑即可。
      - 组被商品使用，组编辑会影响所有使用该组的商品，做好提示说明。
    - 组内子项编辑：
      - 组未被任何商品使用，子项编辑即可。
      - 组被商品使用，子项编辑会影响所有使用该组子项的商品（价格、默认选中除外），做好提示说明。
