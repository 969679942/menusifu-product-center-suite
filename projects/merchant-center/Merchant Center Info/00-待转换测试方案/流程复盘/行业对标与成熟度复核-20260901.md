# 行业对标与成熟度复核

版本：1.0（2026-09-01）  
范围：流程历史与决策可追溯系统、Merchant Center 测试流程治理  
文档归属：`generated-evidence` / `domain-asset` 评审旁证

## 对标范围

本次采用成熟产品公开能力模型进行功能级对标，不将任何单一产品的界面或实现细节照搬到 Merchant Center：

- 测试管理：TestRail、Jira/Xray、Azure Test Plans
- 测试执行与报告：Allure TestOps、ReportPortal
- CI/CD 门禁：GitHub Actions、GitLab CI、Harness
- 运行可观测性：Datadog CI Visibility

## 结论

当前方案在来源追溯、稳定 ID、证据绑定、状态分离、检查点恢复、公共/适配器分层方面已达到项目级可用并接近组织级治理设计；但公共合同、企业治理、用户价值指标和不同 `applicationId` 的真实试点尚未全部闭环，不能标记为平台 GA。

## 缺口与处理

| 缺口 | 处理 | 优先级 | 验收凭证 |
|---|---|---|---|
| 已执行基线与待建设事项混排 | 在 PRD 中拆分“当前基线、产品优先级与实施动作” | 必须 | PRD v2.1 第“当前基线、产品优先级与实施动作” |
| 企业权限、审计、保留和敏感证据控制未形成独立需求 | 新增 FR-025、公共合同 C-008、GAP-009 | 必须 | PRD v2.1、公共平台合同 v1.1 |
| 只有技术门禁，缺少用户价值证明 | 新增 FR-026、公共合同 C-009、GAP-010 | 必须 | PRD v2.1、公共平台合同 v1.1 |
| 平台发布条件缺少统一 Go/No-Go | 新增平台 GA 门槛 | 必须 | PRD v2.1 第 10.1 节 |
| 趋势、flaky、聚类、CI 回写和告警 | 保留为 FR-024 P2 | 可选 | 后续产品化阶段评审 |

## 结果影响

- 文档和索引更新属于 `domain-asset` / `generated-evidence`，不改变代码、适配器、用例、运行账本或历史收据。
- 已有通过结果保持不变，不因本次评审自动重跑或失效。
- 未来公共能力实施时，仅对用例、实现、上下文或已观测产品行为确实变化的范围定向重验。
- 公共平台缺少跨应用试点时继续保持 `deferred/not-ready`；Merchant Center 自身门禁通过时不得被错误阻断。
