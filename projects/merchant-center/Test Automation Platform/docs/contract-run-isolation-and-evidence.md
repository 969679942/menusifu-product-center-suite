# 合同运行隔离与 JSON 证据读取

公共入口：`src/utils/contract-run-isolation.ts`、`src/utils/json-evidence.ts`。

`resolveContractRunIsolation` 接收执行器参数、适配器声明的合同项目名称和显式隔离请求。只有显式选择且全部属于合同项目的字面名称才能跳过业务生命周期。默认全项目、混合项目、通配符和未知项目均不自动隔离；对这些选择强制请求隔离时，必须在认证、浏览器、造数和清理之前失败。缺少项目参数也必须失败。适配器负责声明不含业务依赖的合同项目，setup 和 teardown 必须使用相同判定，且在任何业务资产读写前执行。

`readJsonEvidence` 每次调用重新读取输入，由适配器校验结构。结果分为 available、missing、invalid、unreadable。不可用结果只带稳定原因码，不含源文件内容、异常文本或秘密。治理投影必须显式登记不可用证据，不得回退旧成功、吞掉异常或据此判断产品失败。

公共负向合同覆盖混合/默认/通配符选择、空参数、JSON 损坏、结构错误、读取失败、校验器异常与输入更新。项目集成必须在临时目录执行真实钩子，验证业务资产不变，以及业务模式仍保留原有清理行为。

本变更只修正技术生命周期与报告投影，不产生业务收据，不使历史通过失效，不触发业务重跑。

效率遥测使用 `src/governance/lifecycle-telemetry-validation.ts` 校验统一十个字段。字段存在不能代替有效值；时间必须可解析且先后顺序正确，耗时和等待必须有限非负，等待不得大于总耗时，重试必须为非负整数，指纹及产物引用不能为空。空清单、缺失或损坏输入必须保持未完成；单个输入失败不能中断其他独立阶段。结构完整只表明遥测格式有效，不授权业务或平台完成。
