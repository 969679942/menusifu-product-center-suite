通用前置条件：登录商品中心，选择商户(Brand ID为:000407)，点击确定进入商品中心首页。



## 标准商品

### 用例编号：TC-ITEM-STD-001

用例标题：标准商品创建页展示正确

所属模块：商品管理 → 商品 → 标准商品

优先级：P0

来源：XMind已有 ← 标准商品 / 展示 / 页面展示 / 新建标准商品，页面信息正确

前置条件：
1. 登录商品中心，选择商户(Brand ID为:000407)，点击确定进入商品中心首页
2. 当前品牌下不存在与本次冲突的同名测试商品（本用例商品名称：「标准商品-创建页-{当前时间戳毫秒}」）
3. 已进入 商品管理 → 商品 列表页。

测试步骤：
1. 点击「新增商品」，进入商品类型选择页。
2. 选择「标准商品」，1. 点击侧边栏【商品管理】-【商品】，进入商品列表页
2. 点击右上角【新增商品】按钮，进入选择商品类型页面
3. 点击【标准商品】-【去创建】，进入创建标准商品页面
3. 查看左侧导航及基础信息区域。
4. 依次点击左侧导航：基础信息、商品属性、展示设置、材料信息、统计标签、商品描述。

预期结果：
1. 商品类型选择页展示「标准商品」「套餐」「配菜/加料」三个选项。
2. 成功1. 点击侧边栏【商品管理】-【商品】，进入商品列表页
2. 点击右上角【新增商品】按钮，进入选择商品类型页面
3. 点击【标准商品】-【去创建】，进入创建标准商品页面
3. 页面包含导航栏、基础信息、商品属性、展示设置、材料信息、统计标签、商品描述等模块，行业名称输入框置灰不可手动输入。

### 用例编号：TC-ITEM-STD-006

用例标题：一级分类下无二级分类，可新增商品成功

所属模块：商品管理 → 商品 → 标准商品

优先级：P1

来源：产品确认明确 ← BR-ITEM-CATEGORY-DIRECT-PARENT-CREATE；XMind已有 ← 标准商品 / 新增 / 分类相关校验 / 一级分类下无二级分类，可新增商品成功

1. 打开商品中心

3. 页签切换到商品

5. 填写页面标记为必填的标准商品字段，商品分类选择分类A
6. 提交，查看商品列表页面
7. 确认本次商品出现在列表第一行并核对商品名称、商品类型、规格、商品价格和商品状态
8. 进入详情页核对所选一级分类

预期结果：
1. 一级分类 A 被直接选中，标准商品创建成功
2. 创建成功后列表查询到本次商品且位于第一行，名称、类型、规格、价格和状态与提交内容一致
3. 详情页显示所选一级分类
4. 编辑页一级分类正确回显，修改合法分类后列表和详情持久化新分类
5. 清空分类后允许保存，分类为空且商品状态保持保存前状态

用例标题：一级分类存在二级分类时必须选择二级分类才能完成商品分类选择

测试步骤：
1. 点击侧边栏【商品管理】-【商品】，进入商品列表页
2. 点击【新增商品】并选择【标准商品】，进入创建页

4. 点击一级分类A
5. 点击二级分类A1
6. 填写其他必填字段并保存商品
7. 在列表按商品分类 A1 过滤并进入编辑详情

5. 编辑可重新选择合法一级/二级分类路径，保存后列表过滤和编辑详情回显新叶子分类

### 用例编号：TC-ITEM-STD-009

用例标题：POS名称和送厨名称超长及特殊字符保存后自动格式化

所属模块：商品管理 → 商品 → 标准商品

优先级：P1

来源：XMind已有 ← 标准商品 / 新增 / 商品属性各字段字符格式化校验 / 新增标准商品，POS名称/送厨名称超过20个字符...；BR-FMT-001

前置条件：
1. 登录商品中心，选择商户(Brand ID为:000407)，点击确定进入商品中心首页
2. 已进入 商品管理 → 商品 列表页。
3. 已打开标准商品创建页。
4. 当前品牌下不存在同名测试商品（本用例使用名称「商品-POS名称和送厨名称超长及特殊字符保存后-{当前时间戳毫秒}」）

测试步骤：
1. 展开「高级设置」。
2. 「商品名称」填写 「商品-POS名称和送厨名称超长及特殊字符保存后-{当前时间戳毫秒}」（首尾不含空格）。
3. 「POS 名称」填写超过 20 个字符的内容（**首尾不含空格**；中间可含连续空格；含字母、数字、中文及特殊字符）。
4. 「送厨名称」填写超过 20 个字符的内容（**首尾不含空格**；中间可含连续空格；含字母、数字、中文及特殊字符）。
5. 「起售数量」填写 `1`；「标准价」填写 `10.00`。
6. 点击「保存」。
7. 返回列表，商品名称查询框输入 「商品-POS名称和送厨名称超长及特殊字符保存后-{当前时间戳毫秒}」，等待列表数据自动刷新，进入编辑页，分别记录 `POS_SAVED`。
8. 返回列表，商品名称查询框输入 「商品-POS名称和送厨名称超长及特殊字符保存后-{当前时间戳毫秒}」，等待列表数据自动刷新，进入编辑页，分别记录 `KITCHEN_SAVED`。

预期结果：
1. 页面展示「提交成功」的 Toast 提示。
2. `POS_SAVED`、`KITCHEN_SAVED` 按系统规则格式化（超长截断、连续空格规范、不支持的特殊字符未保留）；**不含首尾空格**。
3. 列表按 「商品-POS名称和送厨名称超长及特殊字符保存后-{当前时间戳毫秒}」 可查询到该商品。
