通用前置条件：已经登录商品中心，并进入到商品中心首页。

## 描述标签

### 用例编号：TC-TAG-DESC-001

用例标题：描述标签页面展示信息正确

所属模块：商品管理 → 标签管理 → 描述标签

优先级：P0

来源：XMind已有 ← 描述标签 / 展示 / 页面展示 / 描述标签页面展示信息正确

前置条件：
1. 已登录商品中心并进入商品中心首页。
2. 测试环境存在执行本用例所需的标签/商品数据。

测试步骤：
1. 进入 商品管理 → 标签管理 → 描述标签 页面。
2. 查看描述标签页面展示

预期结果：
1. 页面展示当前商品库所有的描述标签，列表形式展示，无分页，一页展示完，可向下滚动查看所有的标签
2. 展示的字段如下：描述标签分组名称（中英文上下展示，中文在下） 标签 标签效果 关联商品数量 按钮（标签组：新增标签 编辑 删除 标签：关联商品 解除关联商品 编辑 删除）
3. 标签默认收起，点开左侧的加号可展示该标签组下的所有标签
4. 展示的顺序为：描述标签按照创建的顺序，最新创建的展示在最上面，标签按照明细的排列顺序展示
