# 4. 需求标签管理

描述标签、商品角标、统计标签的列表维护与新增删除。组成：S09（来源 PRD 5.1.1 标签）。

## 需求清单与边界

- 需求范围：商品管理 / 标签管理；三类标签合并作为一个小需求（S09）。
- 不在本需求范围：商品绑定标签（品牌商品新增编辑页，见需求2 / S02）。
- 提测边界：可独立提测；测试数据前缀 `D09_`；用例编号 `TC-REQ09-*`；不依赖其他需求用例。

## 名词解释

- 描述标签：用于 C 端商品展示，一般放在商品名称下，如热销第一名、招牌。
- 商品角标：用于 C 端商品展示，一般放在商品图片上，如 HOT、TOP。
- 统计标签：仅用于数据统计，不对外展示。

## 标签管理

### 标签类型

- 描述标签：用于 C 端商品展示，一般放在商品名称下，如热销第一名、招牌。
- 商品角标：用于 C 端商品展示，一般放在商品图片上，如 HOT、TOP。
- 统计标签：仅用于数据统计，不对外展示。

### 列表

- 点击标签名称进入详情。
- 关联商品：点击列表查看引用商品。
- 操作：删除标签。

### 默认展示与默认收起

- 描述标签：
    - 默认展示：标签名称、标签样式、关联商品数量。
    - 默认收起：第二语言（标签名称）。
- 商品角标：
    - 默认展示：标签名称、标签样式、关联商品数量、有效期。
    - 默认收起：第二语言（标签名称）。
- 统计标签：
    - 默认展示：标签名称、关联商品数量。
    - 默认收起：第二语言（标签名称）。

### 删除

- 如果标签被引用，列表展示引用商品，二次提醒。

### 新增标签

- 描述标签：标签名称、第二语言、标签风格。
- 商品角标：标签名称、第二语言、展示日期、标签风格。
- 统计标签：标签名称、第二语言。

### 设计规范

- 问号说明参照标准规范 4.7 B端产品设计规范。
- 长度填写规范参照 4.1 B端产品设计规范。
- 填入内容限制规范参照 4.11 B端产品设计规范。
- 空数据查询页面，初始化进入页面以设计稿为准。

## 关联说明（PRD 原文·不在 S09 范围）

- 品牌商品新增编辑页：描述标签支持多选，商品角标单选，统计标签多选（商品绑定标签，见需求2）。
- 门店商品：商品角标、描述标签样式与品牌商品一致（门店维护能力，见 PRD 5.5 门店商品）。
