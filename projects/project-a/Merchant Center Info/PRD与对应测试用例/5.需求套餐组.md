# 5. 需求套餐组

套餐组管理、组增删改与同步、份数与子项规则、商品内套餐组合搭配单次加价/默认选中。组成：套餐组 + S06 + S07 + S08(套餐)。

## 组列表与维护（共用）

- 查询条件：
    - 支持组名称、子项名称模糊查询，所有长度限制参照4.1，输入内容类型限制4.11。
    - 支持多语言查询。
    - 查询条件记忆支持，切换页面、页签，返回页面保留原有的查询记录（缓存到账号），数据记忆最多展示最近的10条，记忆做自动清空，重新登陆或关闭浏览器再打开，数据记忆消失。
    - 每次执行查询后，列表自动定位到首页。
    - 每次重置查询后，列表自动定位到首页。
    - 重置后页面状态需与初始进入时完全一致，包括查询条件、列显隐、排序规则等，无任何残留变更。
    - 若当前列表存在筛选条件，翻页时需同步执行查询功能，确保所有页面数据均符合当前条件，避免出现条件外数据。
  - 列表：
    - 组名称支持点击进入详情。
    - 列选择：支持还原默认状态，不支持全部选择数据。
    - 对齐方式：金额右对齐，其他数据左对齐，字段内容参与对齐，字段名一律居中。
    - 操作：删除，即删除整组；删除逻辑详见组的新增&编辑&删除逻辑。
  - 新增：
    - 基础信息：组名称（必填）、第二语言、组编码、展示名称、组描述。
    - 组子项列表：分为基础和更多。
    - 新增子项：输入文本，组内不可重复。
    - 删除子项：删除逻辑详见组的新增&编辑&删除逻辑。
  - 问号说明参照4.7。

## S06 组的新增编辑删除逻辑

- 组增删改逻辑：
    - 组新增：直接新增无影响。
    - 组内子项新增：
      - 组未被任何商品使用，子项新增即可。
      - 组被商品使用，子项新增不会应用到使用该组的商品，做好提示说明。
    - 组编辑：
      - 组内编辑子项价格/默认选中，不会自动同步到已使用选项组的商品中，做好提示说明。
      - 组未被任何商品使用，组编辑即可。
      - 组被商品使用，组编辑会影响所有使用该组的商品，做好提示说明。
    - 组内子项编辑：
      - 组未被任何商品使用，子项编辑即可。
      - 组被商品使用，子项编辑会影响所有使用该组子项的商品（价格、默认选中除外），做好提示说明。
    - 组删除：
      - 组未被任何商品使用，组内无子项，组删除即可。
      - 组被商品使用，解除和商品关联关系，子项删除后，组才可删除，做好提示指引。
    - 组内子项删除：
      - 组未被任何商品使用，子项删除即可。
      - 查询所有使用该子项商品清单，都×掉，才可删除子项；所有子项删除后，空组情况提示不可保存。
  - 保存与关闭：
    - 保存按钮：
      - 校验组内容，若不完整，提示“请补充完整信息”。
      - 若完整，提交并保存，所有信息生效。
    - 关闭按钮：
      - 无保存数据：直接关闭，不保留数据。
      - 已有数据编辑中：
        - 若组内容不完整，提示“请补充完整信息”。
        - 若组内容完整，弹出提示“是否保存修改？”
        - 选择【保存修改】执行保存。
        - 选择【放弃修改】关闭弹窗，不保存调整。
  - 新增组（未添加子项）：
    - 点击【保存】提示“请先添加子项再保存”。
    - 点击【关闭】直接关闭，不保存数据。
  - 编辑组（删除所有子项）：
    - 点击【保存】提示“请添加至少一个子项后再保存”。
    - 点击【关闭】提示“请保留子项，否则修改不生效”；关闭后，改动不保存。
  - 商品引用组时，同步组字段信息：
    - 规格组：基础信息同步规格组名称、组第二名称；商品信息同步规格名称、规格名称第二语言、规格值、默认选中；规则同步排序。
    - 口味组：基础信息同步口味组名称、组第二名称；商品信息同步口味名称、口味名称第二语言、加价、默认选中；规则同步排序。
    - 做法组：基础信息同步做法组名称、组第二名称；商品信息同步做法名称、做法名称第二语言、加价默认选中；规则同步排序。
    - 加料组：基础信息同步加料组名称、组第二名称；商品信息同步加料名称、加料名称第二语言、编码、最小数量、最大数量、子项商品价格、单次加价、默认选中；规则同步排序、最少选择份数、最多选择份数、份数内免费。
    - 套餐组：基础信息同步套餐组名称、组第二名称；商品信息同步商品名称、名称第二语言、编码、最小数量、最大数量、子项商品价格、单次加价、默认选中；规则同步排序、添加、移除、最少选择份数、最多选择份数、份数内免费。
  - 组内部分字段不展示在商品上。
  - 组基本信息自动同步，商品信息、规则不自动同步。
  - 五个组被引用后，组修改保存时增加同步流程（同步到已关联商品）。
    - 先执行保存流程，再执行同步流程，同步商品默认勾选。
    - 展示的商品为与该组已关联的商品。
  - 五个组新增组覆盖同步商品功能——同步至商品。
    - 同步至商品范围：所有状态为启用（起售）的商品。
    - 两个Tab，已关联组商品、新商品。
    - 已同步商品默认勾选。其他未同步过商品手动选择。
    - 覆盖同步范围：商品信息、规则信息。
  - 商品可修改内容：移除组子项，可以选择组内子项。

## S07 套餐组&加料组商品规则

- 组规则：
    - 最少选择份数：必填，组内所有子项累加最少可选择数量，输入范围在0~999，自然数。
    - 最多选择份数：必填，组内所有子项最多可选择数量，最多选择份数≥最少选择份数，输入上限999，自然数。
    - 份数内免费：必填，多少份内免费，规则按照加入的子项顺序计算，输入在[最少,最大]之间。
    - 相同商品是否合并展示：同spu商品不同sku合并展示。
  - 子项列表：
    - 最小数量：子项单个商品最小数量，输入限制≥1，自然数，默认值为1，不可以为空。
    - 最大数量：子项加购数量上限，输入限制999内，自然数，不输入为空，逻辑按照999处理。
    - 价格：子项商品的标准价，列表中展示。
    - 单次加价：默认展示为子项商品标准价，用户可以手动修改，用户输入必须≥0，支持2位小数。如输入0元，提交时二次提示弹窗：有子项加价为0元，请确认是否提交。（组编辑/商品编辑都支持）
    - 口味、做法可以为0，默认为空，按0处理。
    - 默认选中：下单时，默认选中某个子项，点餐时可取消选中。
  - 业务限制：
    - 组最小数量≤子项的选择数量累加≤组最大数量。
    - 子项的最小数量≤最大数量。
  - 添加组合搭配：
    - 最少选择数量、最多选择数量、份数内免费设为必选，输入范围与套餐组管理中一致。
    - 标准价改为价格，按照最小数量、最大数量、价格、单次加价、默认选中展示。
    - 单次加价、默认选中商品内可编辑。

## S08 商品内选项组（套餐-组合搭配）

- 商品内选项组（口味、加料、做法、套餐-组合搭配）添加后支持编辑加价/单次加价、默认选中。
  - 加价/单次加价：
    - 商品添加对应组，带入组内维护的价格。
    - 添加到商品内可调整子项价格，编辑后只在商品内生效，不影响选项组信息。
    - 商品添加组内新子项时，取组内新子项最新价格设置。
  - 默认选中：
    - 商品添加对应组，带入组内维护的默认选中。
    - 添加到商品的选项组，可调整组内默认选中。
    - 商品添加组内子项，提交时校验默认选中唯一性。
      - 商品内新增选项组，直接将选项组内默认选中带入（如有）。
      - 商品内已有选项组，且未维护默认选中，添加子项，子项有默认选中，带入默认选中；子项无默认选中，带入后整组无默认选中信息。
      - 商品添加选项组，选项组已有默认选中子项，选项组新增子项，且该子项非默认选中项。商品添加子项，默认选中项不变。
      - 商品添加选项组，选项组已有默认选中子项，选项组新增子项，将新增子项设置为默认选中项。商品添加该子项，识别商品内该选项组是否已有默认选中，如果已有，新增子项的默认选中不带入；如果没有，新增子项的默认选中带入商品。
  - 组编辑逻辑调整：
    - 组内编辑子项价格/默认选中，不会自动同步到已使用选项组的商品中，做好提示说明。
    - 组编辑：
      - 组未被任何商品使用，组编辑即可。
      - 组被商品使用，组编辑会影响所有使用该组的商品，做好提示说明。
    - 组内子项编辑：
      - 组未被任何商品使用，子项编辑即可。
      - 组被商品使用，子项编辑会影响所有使用该组子项的商品（价格、默认选中除外），做好提示说明。
