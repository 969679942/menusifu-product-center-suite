# 8. 需求调味模版

多门店调味模版维护、选调味、选门店、下发方式及**下发记录**查询。组成：S-FLV-02（`TC-FLV-TPL-*` + `TC-FLV-REC-*`）。

## 需求独立性

| 项 | 说明 |
|----|------|
| 数据前缀 | `D8_` |
| 用例编号 | `TC-需求8-*`（原 `TC-FLV-TPL-*` / `TC-FLV-REC-*`） |
| 依赖 | 需求7（品牌调味数据；禁用项不可入模版） |
| 不在范围 | 品牌 CRUD（需求7）、门店/POS（需求10） |
| 单门店 | 不展示调味模版菜单（BR-FLV-006） |
| 验收依据 | 业务规则 §11、§12 |

## 下发记录（§12 补充）

- 列表字段：任务名称、下发门店数、执行状态、操作人、执行时间。
- 任务名称规则（BR）：调味模板名称 + 11 位数字（与 Lark PRD「调味下发记录+11位数字」冲突处以 BR 为准）。
- 单击下发门店数：跳转记录详情，展示本次下发门店明细。
- 下发详情：选择的门店、选择的调味、下发方式。
- 查询：任务名称模糊/精确；门店名称或编码；执行状态；组合查询；重置。
- 不支持：定时下发、差异对比（§12 刻意不写）。

## 调味模版下发

- 模版列表字段：模版名称、模版说明、调味数量（系统计算）、适用门店（系统计算，使用该模版的门店数量）。
- 下发流程：
    - 品牌只有一个门店：将「所有调味」按「完全替换门店调味」方式下发；即所有调味对应一个「调味模版」。
    - 品牌有多个门店：选择模版进行下发。
- 下发方式：
    - 枚举值：合并调味、覆盖同名下发 / 完全替换门店调味。
    - 默认选中：合并调味、覆盖同名下发。
    - 其他：必选、单选。
- 下发记录：
    - 名称规则：「调味下发记录 + 11 位数字」。
    - 单击：跳转【记录详情】页面。
- 下发详情：展示选择的门店、选择的调味、下发方式。
- 下发影响：
    - 不影响商品的状态排序。
    - 新增调味排序排在后面。
- 操作：
    - 下发：单击进入【下发流程】。
    - 新增：单击跳转【新增模版】。
    - 删除：二次确认后直接删除。

### 新增模版

- 模版信息：
    - 模版名称：必填，文本，最多 20 字，不可重复；重复时提示内容重复。
    - 模版说明：非必填，文本，最多 50 字。
- 调味信息（选择后回显）：调味名称、调味第二语言、调味组名称。

### 模版-选择调味

- 调味列表：调味组名称、调味组第二语言、调味组调味数量、调味名称、调味第二语言。
- 已选择调味：展示选择数量；字段含调味名称、调味第二语言、调味组名称。

### 下发流程-选择门店

- 门店列表：门店名称、门店编码（MID）、区域（可为空）、邮编（可为空）、地址信息（可为空）。
- 已选择门店：展示选择数量；字段含门店名称、门店编码。
