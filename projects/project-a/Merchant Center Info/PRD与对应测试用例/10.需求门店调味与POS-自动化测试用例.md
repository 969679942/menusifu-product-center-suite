> 写入 `3.商品中心-商品管理-调味管理-自动化测试用例.md` 顶部，**每条用例不再重复**。

## 登录与权限

- 使用执行计划绑定的测试账号登录商品中心（品牌视角）
- 门店/POS 用例另需门店上下文 S1 与 POS **30.16.6.7** 环境
- 账号须具备商品管理 / 调味管理读写权限

## 数据命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 品牌调味组 | `TC_FLV_GRP_{正式编号}` | `TC_FLV_GRP_015` |
| 品牌调味项 | `TC_FLV_ITEM_{正式编号}` | `TC_FLV_ITEM_015` |
| 调味模板 | `TC_FLV_TPL_{正式编号}` | `TC_FLV_TPL_008` |
| 下发记录查询 | `TC_FLV_REC_{正式编号}` | `TC_FLV_REC_002` |
| 门店引用 | `TC_FLV_STORE_S1` / `TC_FLV_REF_{编号}` | `TC_FLV_REF_011` |
| PRD 需求前缀 | `D7_` / `D8_` / `D10_` + 场景 | `D8_模板下发-TC-需求8-020` |

- 执行前确认造数对象已存在（Readiness 未通过则 block/skip）

## 数据依赖用例（UI + 平台造数）

> 本文档 **仅含 UI/E2E 可执行用例**；接口造数/清理 **不写入本文档**。

- 前置含「已下发」「已存在模板/调味组/下发记录」→ 须写 **`数据标识`** + **Readiness**
- 步骤按固定名称/查询关键字定位，禁止「找一条满足条件的调味」

## 导航入口

| 子模块 | 路径 |
|--------|------|
| 品牌调味 | 商品管理 → 调味管理 → 调味 |
| 调味模板 | 商品管理 → 调味管理 → 调味模板 |
| 下发记录 | 商品管理 → 调味管理 → 下发记录 |
| 门店调味 | 门店商品管理 → 门店调味 |
| POS 全局调味 | POS 门店 S1 全局调味/点单入口（E2E） |

- 起始页与步骤第 1 步一致；保存/确认/查询统一加引号

## 跨模块 / POS（TC-FLV-XMOD-* / TC-FLV-POS-*）

- `TC-FLV-POS-*` 与部分 `TC-FLV-XMOD-*` 为 **E2E**
- 品牌下发、模版下发、菜单下发、同步 POS 由执行计划承担

## 自动化生成注意

- 正式前置里的 **「测试数据满足本场景（调味组/调味项/模板/下发记录等）」** 为占位句，**不触发** `数据标识` / Readiness
- **缺省页新建**（如 SEA-009）：前置应为「当前品牌下无调味数据」，步骤须字段级展开，禁止「点击新增入口，填写表单并确认保存」
- 命名：`TC_FLV_GRP_{正式编号}`、`TC_FLV_ITEM_{正式编号}`、`TC_FLV_TPL_{正式编号}`；PRD 小需求另用 `D7_/D8_/D10_` 前缀

### 用例编号：TC-需求10-001

用例标题：批量启用调味成功且下发后POS展示

优先级：P1

执行类型：E2E

执行策略：SINGLE_SCENARIO

数据标识：
- 目标对象：`TC_FLV_GRP_038`

数据准备：
- 由执行计划/平台造数脚本完成（**不在本文档展开**）；跑本用例前须已按「数据标识」造好对象。

失败分类：
- Readiness 未通过 / 造数未完成 → 环境/数据问题
- 业务断言不符（该失败却成功、提示文案错误等） → 产品缺陷

起始页面：
- 导航：商品管理 → 调味管理 → 调味
- 就绪条件：页面出现调味列表或行业调味库入口

前置条件：
1. 已登录商品中心，具备商品管理权限。
2. Readiness：列表按 `TC_FLV_GRP_038` 可查到目标对象。若查不到 → **环境未就绪（block/skip）**，不判产品缺陷。
3. 从起始页面进入品牌调味页。

测试步骤：
1. 勾选调味项后执行批量操作。

预期结果：
1. 下发后pos展示调味。
