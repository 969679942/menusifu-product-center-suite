# 不可变观察快照

`publishImmutableArtifact` 属于 public-core。适配器必须显式提供绝对产物根目录、根内相对路径、已脱敏内容和更新原因。禁止写入凭据、cookie、浏览器状态或秘密配置。

更新 latest 前，在适配器根目录 `.artifact-history/objects` 用内容 SHA-256 独占创建前后内容快照。已有对象只校验、不覆盖；损坏时阻断。独占发布锁保护同一 latest；越界、链接重定向、对象写入失败、并发变更均不得覆盖原视图。

不可变 transition 保存原值、新值引用和原因，状态固定为 `prepared`，表示覆盖前已记录意图，不能单凭它断言发布成功。调用成功或 latest 内容哈希可证明当前发布内容；中断后先核对，不删除别人的锁。历史修正必须另外保留所消费输入，原始指标不得改写。快照不授权业务通过，也不把静态审计耗时变成业务吞吐量。

公共接入包括迁移报告、readiness、评审队列/发布时效复核、最终裁决和外部依赖观察；领域入口覆盖由项目适配文档登记。适配器把 `.artifact-history` 归为 generated-evidence，避免每次新观察触发源码迁移基线重新接受。其他 latest 写入器仍需逐项接入，不能宣称全平台快照覆盖完成。快照在程序合同内不可覆盖，并不等同于外部存储 WORM 或抵御管理员篡改。
