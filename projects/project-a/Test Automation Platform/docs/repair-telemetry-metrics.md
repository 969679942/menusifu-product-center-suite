# 整改遥测观察统计

公共汇总返回 `scope=telemetry-ledger-events` 与 `currentRunCountsAvailable=false`。事件数是账本行数，不代表尝试数、业务执行数、通过数或终态数；当前运行计数必须另由 run 索引的报告和选择集证明。

缺失/无效/不可读账本的事件与指标为 null；可读空账本的事件数为 0，但运行成本仍不可用。只有单一 application/session 且每个效率观察都明确提供有效值时，才提供该字段的观察值合计。部分记录缺值、负值、非有限值、非整数启动数及混合会话均返回 null。此合计不是未经去重的真实运行成本证明，不能消费为当前运行结果。

`browserStarts` 与 `avoidableBrowserStarts` 分别来自对应字段，禁止将可避免启动次数冒充总启动次数。真实零值保留；未知不回填零。原始账本不改写，配置读取/解析错误只返回安全状态，不包含原文或异常消息。涉及历史测量修正仍须保存原始输入和不可变修正记录。

逐调用运行计数使用 [逐调用索引统计](indexed-run-telemetry.md)，从独立声明和账本快照重新计算。项目审计并列展示两种统计；事件账本仍不具备当前运行计数权限。
