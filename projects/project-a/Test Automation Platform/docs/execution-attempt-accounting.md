# 逐尝试与用例执行统计

公共证据账本 1.1.0 / 1.2.0 保存 runId、独立选择集指纹及全部尝试，包括未结束和跳过记录。每个尝试保留 Playwright testId、retry、开始时间、耗时和原始收据。不同测试身份共享 caseId、重复或断档 retry、越界用例及无效运行身份使统计无效，未知计数为 null。

`cases` 是每个 caseId 最新 retry 的非跳过终态投影；新失败、新跳过或未结束尝试均不回退旧成功。实际尝试数排除跳过登记；唯一实际执行集合、当前终态、跳过和未完成集合独立保存。进行中的尝试已计入启动事实，但不授权终态。

测试尝试累计工作耗时与时间区间并集分别保存；有未结束尝试时两者为 null。这些数值只描述测试尝试，不等于完整 runner 耗时，也不从缺失观察猜测浏览器启动次数或可避免成本。

runner、收据导入和项目终态适配器在消费前从原始尝试重新计算投影。修改汇总或拼接与原始尝试不一致的旧成功不能通过当前投影检查。1.2.0 通过逐调用索引绑定独立声明和内容寻址快照；消费入口同时验证当前视图与快照一致。仅重算投影不证明原始历史未经删改，索引也不是外部签名信任根。通过资格仍由当前业务收据校验，尝试统计从不授权业务通过。旧格式历史账本保留原有兼容导入路径，不因本次报告合同变更重跑历史业务。

本合同的计数覆盖单次 Playwright reporter 生命周期；同 runId 多进程调用现由 run-evidence-index 独立保存，详见 [运行证据索引](run-evidence-index.md)。跨调用累计尝试统计见 [逐调用索引统计](indexed-run-telemetry.md)；分片协调和不完整批次内的定向恢复仍未完成，不能由同一 runId 或 latest 文件存在推断完整尝试历史。
