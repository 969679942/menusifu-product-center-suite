# 业务操作与调用记录映射

`OperationOccurrenceMapping` 由当前独立合同提供，不能从待验收收据反推。每个源步骤声明且只声明一个业务操作；该操作绑定具体 `executableOperationKey` 的第 N 次调用。调用启动序列必须为互不重复的正整数，嵌套完成顺序不影响身份。

同一调用不可复用为多个步骤证据；来源步骤集合与业务绑定集合必须完全一致。辅助记录逐项声明具体方法及调用次数，可以显式为可选，但不可使用通配集合。未声明记录、缺少必需辅助记录、缺少业务调用、重复/未知序列以及任何不完整执行观察都阻断。

映射结果只引用原收据的观察、状态、时间和序列；不生成 passed 或 observed 值，不修改原记录。发布资格仍校验原始内容指纹、当前用例与实现、上下文、完整断言和清理。直接业务操作收据可保持原路径，但项目适配器必须证明其声明覆盖当前来源。

该能力只解决操作身份与收据形态的对账。方法与业务步骤语义是否一致，仍须由当前源码/适配器及来源准入证明；不能用通用整案包装或历史方法清单虚构覆盖。
