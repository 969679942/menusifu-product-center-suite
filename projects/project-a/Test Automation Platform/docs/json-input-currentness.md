# JSON 来源当前性合同

`verifyJsonInputCurrentness` 对照已保存的 `{ path, fingerprint }` 声明和适配器独立配置、刚读取且已校验结构的完整输入集合。公共层不从声明路径发现或读取文件，也不持久化原值。适配器负责来源位置、读取权限及结构合同；公共层负责唯一性、集合守恒、可用性和逐项内容指纹比较。

指纹使用解析后 JSON 的序列化内容，忽略空白和 BOM，保留键及数组顺序。空输入、重复身份、缺少或额外声明、不可用来源及内容变化均不能返回 current。诊断只含规范原因码。

current 只证明声明与本次读取内容匹配，不证明业务执行通过、运行证据完整或跨系统平台完成。调用方不得把待验收声明作为当前输入集合；下游必须在消费时重新读取，不能沿用生成报告时的内存对象。
