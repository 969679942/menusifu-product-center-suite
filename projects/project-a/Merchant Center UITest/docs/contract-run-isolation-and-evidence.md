# 商品中心合同运行适配

项目适配器 `adapters/test-automation-platform/contract-run-isolation.ts` 将无业务依赖的 `api` 项目和 `PC_CONTRACT_ISOLATED=1` 映射到公共合同判定。全局 setup/teardown 在业务遥测、认证态、checkpoint、runtime lock、Allure 和历史报告维护之前调用该判定。单独选择 `api` 自动隔离；默认浏览器或混合项目带隔离标记时提前拒绝。合同项目不得增加业务 setup 依赖。

`scripts/build-product-center-blocker-summary.ts` 在每次构建时通过公共 JSON 证据读取合同消费认证配置预检、公共最终门禁、维护性、正式整改报告、效率审计和最近调度器。项目只声明路径、结构和业务文案。配置就绪不等于认证成功；调度阻断不自动等于授权阻断；输入异常属于证据缺口。摘要不能授权任何用例通过。

`product-center-contract-hooks-isolation.contract.spec.ts` 在临时目录调用真实全局钩子，使用模拟认证态、损坏检查点、锁、Allure 文件和 110 份历史耗时报告；隔离/混合拒绝路径必须保持文件逐字节不变，业务路径必须保留清理。摘要合同使用独立临时输入，覆盖更新读取、异常显式化和状态分类，不读写正式治理输出。

目的：阻止合同测试污染业务历史，避免治理摘要丢失或沿用过期输入。预期结果：负向合同、类型和架构门禁通过。后续影响：已有业务通过事实不失效，不重跑业务；仍缺真实收据和授权的事项继续保持未完成。

效率审计脚本在每次调用时校验清单，按适配器声明逐阶段读取输入，并消费公共十字段遥测校验。缺失、损坏、不可读产物及无效遥测独立计数，继续审计其他阶段；空清单不能通过。敏感字段只登记阶段及安全类别，不保存源值。独立临时输入合同覆盖损坏输入后继续、空值、空清单、重复构建、读取失败和秘密脱敏。
