## 安全规则

- 只创建、编辑或删除名称以 `AUTO_AUDIT_` 开头的数据。
- 创建成功后立即登记服务端 ID。
- 清理任务逆序执行，并同时验证 UI 与 API 不存在。
- 定位器出现 0 个或多个匹配时立即失败。
- 不从 provisional、blocked、unresolved 记录生成断言。
